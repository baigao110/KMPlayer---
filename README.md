# KMPlayer 媒体信息与资源集合页面

这是一个功能丰富的HTML单页应用，集成了媒体信息展示、实用工具、在线电台播放、倒计时管理以及资源导航等多种功能。页面设计采用了科技感风格，并支持深色/白色主题切换。

## ✨ 主要功能

### 🎬 KMPlayer 媒体信息展示
- 展示了KMPlayer播放器对于视频文件（如电视剧《外科风云》）的详细媒体信息。
- 提供**英语原文**和**中文翻译**两种视图，方便技术参考与学习。

### 🛠️ 实用工具集
- **Unix时间戳转换**：实现日期时间与Unix时间戳的相互转换。
- **计时器**：支持自定义倒计时（年/月/日/时/分/秒），具有开始、暂停、重置功能，并支持8种不同的显示模式（如“天:时:分:秒”、“年:月:天”等）。
- **秒表**：支持开始、暂停、记录圈数，并能自动统计并高亮显示最快和最慢圈速。
- **链接连通性测试**：可自动或手动测试页面内所有链接的可用性，并显示测试结果。

### 🎵 在线音乐播放器
- 内置了超过40个网络电台（如AsiaFM、ACG动漫音乐电台等），可在线收听。
- 支持**自定义播放**：可以通过输入音频文件（MP3、WAV等）的URL或拖拽本地音频文件进行播放。
- 提供播放/暂停、上一曲/下一曲、音量控制及播放进度条等完整控制功能。

### ⏳ 智能倒计时系统
- **固定倒计时**：从页面加载时刻开始计算，到目标时间的固定差值。
- **实时倒计时**：动态显示当前时间到目标时间的剩余时间。
- **自定义倒计时**：用户可以自由创建任意名称、目标日期和时间的倒计时，并可进行管理（查看、删除）。
- 内置了两个预设倒计时示例：
    - 华都云境悦府收房倒计时（2026-10-31）
    - GTA6游戏发售倒计时（2026-11-19）
- 倒计时支持8种显示模式切换（与计时器模式一致）。

### 🔗 资源导航
- 分类整理了各类实用链接，包括：
    - **游戏下载**
    - **系统下载**
    - **学习资源**
    - **资源搜索**
    - **实用工具**
    - **技术论坛**
    - **电视台在线直播**
- 页面还集成了**抖音直播间和个人账号**的快捷入口。

### 🎨 交互与视觉
- **深色/白色主题**：一键切换，适应不同使用环境。
- **鼠标交互特效**：点击页面会弹出“社会主义核心价值观”词语；右键点击会显示友好的提示弹窗。
- **浏览器标题动画**：标题栏会循环显示多条欢迎信息，增加趣味性。

## 🚀 如何使用

1.  直接在浏览器中打开 `index.html` 文件即可运行。
2.  所有工具和内容默认处于折叠状态，点击标题栏（如“Unix时间戳与日期相互转换工具”）即可展开或收起。
3.  页面底部右下角为音乐播放器，点击 **“→”** 按钮可展开，进行电台选择、自定义播放等操作。
4.  倒计时和计时器的显示模式可以通过点击对应的显示区域进行循环切换。

## 💻 技术栈

- **HTML5**
- **CSS3**：包括Flexbox、Grid、动画、渐变、媒体查询等。
- **原生JavaScript (ES6+)**：实现了所有交互功能、计时器、音频播放、数据持久化（使用LocalStorage）等。
- **Web Audio API**：用于计时器结束时的提示音。

## 📌 注意事项

- 音乐播放器中的部分网络电台链接可能因源站变更而失效，您可以自行修改 `stations` 数组中的链接。
- 链接连通性测试功能受到浏览器跨域策略（CORS）的限制，测试结果仅供参考。
- 页面数据（如自定义倒计时、主题设置等）会保存在浏览器的本地存储中，清除浏览器缓存会导致数据丢失。
